JEENU CORPORATION — FULL WEBSITE PACKAGE
========================================

This is the updated multi-page static website for https://jeenucorporation.com.
It uses the supplied Jeenu Corporation artwork:
- assets/jeenu-primary-logo.png — primary horizontal logo
- assets/jeenu-j-leaf-mark.png — J-and-leaf symbol
- assets/jeenu-app-icon.png — app/favicon icon

Pages:
- index.html — Home
- about.html — About
- product.html — Product information
- contact.html — Contact
- privacy.html — Privacy
- 404.html — Not found page

Deployment to Cloudflare Pages:
1. Extract this ZIP.
2. Upload the contents of the Jeenu_Corporation_Full_Website_Updated folder as the static site assets, or connect the folder/repository to Cloudflare Pages.
3. Set the build command to blank / none and the output directory to the folder containing index.html.
4. Keep the existing domain and email DNS records unchanged when deploying.
5. Test the root domain, www redirect, all navigation links, mobile layout, and contact links after deployment.

Important:
- This is a static HTML/CSS/JavaScript site; no build step is required.
- Logo files are PNG artwork supplied by the user. They are displayed as provided and are not converted into vector artwork here.
- Confirm contact email/WhatsApp details before publishing if you want those channels activated.
- Product text is descriptive and should be checked against final product specifications before publication.
